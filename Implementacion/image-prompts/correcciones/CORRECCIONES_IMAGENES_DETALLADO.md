# Corrections for generated images - Pre-algebra (detailed)

Base path: `Implementacion/image-prompts/referencias/generated`

Total inventoried: 70 images.

## Recommended flow

1. Fill in one sheet at a time.
2. Copy that sheet into the session that will generate the new image.
3. Ask for a single new version: `Image N1-01 v5`, `Image N2-08 v5`, etc.
4. Do not apply global changes unless you explicitly write: `apply to all`.
5. When an image is done, change `Status` to `Approved`.

## Base prompt to paste into the other session

```text
We will work only on the image given in this sheet.
Keep the overall style of the Pre-algebra set and do not redesign images that are already approved.
Generate a single new version of this image.
Name the result with the sheet ID and the next version.
Do not apply these corrections to other images unless I say so explicitly.
```

## Statuses

- `Pending`: not reviewed yet.
- `Needs v5`: needs a new version.
- `Approved`: do not touch.
- `Discard`: do not use in the product.
