#### 2.3 Situación problema

**Título visible:**
```
Situación: panes para compartir
```

**Texto visible:**
```
Un grupo de 4 amigos compra 3 panes.

Quieren repartirlos en partes iguales, sin que sobre ni falte nada.
```

**Pregunta inicial:**
```
¿Cuánto pan debe recibir cada persona?
```

---

#### 2.4 Interacción 1 — Representar el reparto

**Pregunta visible:**
```
Si hay 3 panes para 4 personas, ¿qué fracción representa lo que recibe 
cada persona?
```

**Opciones de respuesta:**
- 3/4
- 4/3
- 3 + 4
- 4 − 3

**Respuesta esperada:** 3/4

---

#### 2.5 Retroalimentación para Interacción 1

##### Si responde **3/4**

**Título del recuadro:**
```
✓ Correcto
```

**Retroalimentación de Katia:**
```
Cada persona recibe 3/4 de pan.

Esto significa que los 3 panes se reparten entre 4 personas.

3/4
```

##### Si responde **4/3**

**Título del recuadro:**
```
⚠ Revisemos el orden
```

**Retroalimentación de Katia:**
```
La fracción debe expresar:

panes ÷ personas

Aquí se reparten 3 panes entre 4 personas, por eso escribimos:

3/4
```

**Misconception tag registrado:** `confunde_numerador_denominador`

##### Si responde **3 + 4** o **4 − 3**

**Título del recuadro:**
```
⚠ No estamos sumando ni restando
```

**Retroalimentación de Katia:**
```
El problema no pregunta cuántos elementos hay en total ni cuántos faltan.

Pregunta cómo repartir 3 panes entre 4 personas. Para eso usamos una fracción:

3/4
```

**Misconception tag registrado:** `no_interpreta_fraccion_como_reparto`

---

#### 2.6 Visualización del reparto

**Título visible:**
```
Ver el reparto
```

**Texto visible:**
```
Podemos imaginar que cada pan se divide en 4 partes iguales.

Como hay 3 panes, cada persona recibe una parte de cada pan.

En total, cada persona recibe:

1/4 + 1/4 + 1/4 = 3/4
```

**Diálogo de Katia:**
```
Una fracción puede representar una parte de una unidad, pero también puede 
representar un reparto.
```

#### 2.7 Pausa conceptual — Fracción como división

**Título visible:**
```
Pausa: una fracción también es una división
```

**Texto visible:**
```
La fracción:

3/4

también significa:

3 ÷ 4

Es decir, repartir 3 unidades entre 4 partes iguales.
```

**Diálogo de Katia:**
```
Esta idea es importante porque nos permite pasar de fracciones a decimales.

Una fracción no es un tema separado de la división: muchas veces es otra 
forma de escribirla.
```

---

#### 2.8 Interacción 2 — Fracción como división

**Pregunta visible:**
```
¿Qué división representa la fracción 3/4?
```

**Opciones de respuesta:**
- 3 ÷ 4
- 4 ÷ 3
- 3 + 4
- 4 − 3

**Respuesta esperada:** 3 ÷ 4

---

#### 2.9 Retroalimentación para Interacción 2

##### Si responde **3 ÷ 4**

**Título del recuadro:**
```
✓ Correcto
```

**Retroalimentación de Katia:**
```
La fracción 3/4 significa dividir 3 entre 4.

3/4 = 3 ÷ 4
```

##### Si responde **4 ÷ 3**

**Título del recuadro:**
```
⚠ Cuidado con el orden
```

**Retroalimentación de Katia:**
```
En una fracción, el numerador indica lo que se divide y el denominador 
indica entre cuántas partes se divide.

Por eso:

3/4 = 3 ÷ 4

No es 4 ÷ 3.
```

**Misconception tag registrado:** `confunde_numerador_denominador`

##### Si responde **suma o resta**

**Título del recuadro:**
```
⚠ La fracción indica división
```

**Retroalimentación de Katia:**
```
La raya de fracción también puede leerse como una división.

3/4 = 3 ÷ 4
```

**Misconception tag registrado:** `no_interpreta_fraccion_como_division`

#### 2.13 Decimales exactos y periódicos

**Título visible:**
```
Dos formas de decimales racionales
```

**Texto visible:**
```
Algunos racionales se convierten en decimales exactos, es decir, decimales 
que terminan.

Ejemplo:

1/4 = 0.25

Otros racionales se convierten en decimales periódicos, es decir, decimales 
que repiten una cifra o grupo de cifras infinitamente.

Ejemplo:

1/3 = 0.333…
```

**Diálogo de Katia:**
```
Aunque 0.333… no termina, sí es racional, porque viene de una fracción:

1/3
```

---

#### 2.14 Formalización

**Título visible:**
```
¿Qué son los números racionales?
```

**Texto visible:**
```
Los números racionales son aquellos que pueden escribirse como una fracción 
entre dos números enteros, siempre que el denominador sea distinto de cero.

Se representan con la letra Q:

Q = { a/b | a, b ∈ Z, b ≠ 0 }

Esto significa que a y b son números enteros, pero b no puede ser cero.
```

Ejemplos:

−3 = −3/1

0 = 0/1
```

**Diálogo de Katia:**

Por eso, los enteros están dentro de los racionales.
```

### A5. Notas pedagógicas inline

**[NOTA PEDAGÓGICA — Fracción como reparto Y como división]**
La doble interpretación de la fracción (parte de unidad / operación de división) es el corazón conceptual de este bloque. La situación de panes ancla la fracción en una experiencia de reparto antes de formalizar 3/4 = 3 ÷ 4. Esta secuencia previene la concepción errónea de la fracción como "dos números con una raya".

**[NOTA PEDAGÓGICA — Decimales periódicos también son racionales]**
Una misconception persistente es creer que todo decimal infinito es irracional. Por eso el bloque presenta explícitamente 0.333… = 1/3 como ejemplo de decimal infinito **periódico** que sí es racional. La distinción exacto/periódico/no-periódico prepara el terreno para el bloque de irracionales (B07).

**[NOTA PEDAGÓGICA — Inclusión Z ⊂ Q]**
La nota "todo entero es racional" (5 = 5/1) refuerza la estructura de inclusión entre conjuntos. Esto es crítico para los clasificadores posteriores (B10, B11), donde el estudiante debe reconocer que un número puede pertenecer a múltiples conjuntos simultáneamente.

### A6. Accesibilidad

- **Colores:** No dependen únicamente de rojo/verde; se usan símbolos ✓ y ⚠.
- **Fracciones:** Renderizadas con KaTeX, con ARIA-label legible ("tres cuartos", no "3/4").
- **Visualización del reparto:** Descripción ARIA del proceso de división de panes.
- **Decimales:** "cero punto setenta y cinco" anunciado correctamente; "cero punto tres periódico" para 0.333…
- **Contraste:** Relación mínima 4.5:1.
- **Símbolos:** ∈, ≠, Q, ⊂ con etiquetas ARIA.

### A7. Notas de citas pedagógicas

- **Fracción como reparto:** Kieren (1976) — las fracciones tienen múltiples sub-constructos (parte-todo, cociente, razón, operador).
- **Conexión concreto-simbólico:** Bruner (1960) — la enseñanza progresa de lo enactivo (repartir panes) a lo simbólico (3/4).
- **Misconception de decimales infinitos:** Sirotic & Zazkis (2007) — los estudiantes frecuentemente confunden "infinito" con "irracional".
