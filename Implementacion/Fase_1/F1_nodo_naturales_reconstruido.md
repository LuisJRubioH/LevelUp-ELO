```
Naturales: contar cantidades completas
```

**Subtítulo:**

#### 2.2 Diálogo inicial de Katia

**Contexto visual:** Katia aparece señalando el primer peldaño de la escalera.

**Diálogo de Katia:**
```
Empecemos con los números que usamos desde muy temprano: los números para contar.

Cuando contamos objetos completos, como cuadernos, lápices, estudiantes o bolsas 
de alimento, usamos números naturales.

En este nivel vamos a trabajar con esta convención:

N = {0, 1, 2, 3, 4, …}

Eso significa que aquí consideramos que el cero también pertenece a los naturales.
```

---

#### 2.3 Situación problema

**Título visible:**
```
Situación: bolsas de alimento
```

**Texto visible:**
```
Un granjero necesita 10 bolsas de alimento para sus animales.

En la granja tiene 3 bolsas y compra 5 bolsas más en el mercado.
```

**Preguntas guía (aparecen en secuencia):**
1. ¿Cuántas bolsas tiene ahora?
2. ¿Le alcanzan para alimentar a sus animales?
3. Si no le alcanzan, ¿cuántas bolsas le faltan?

---

#### 2.4 Interacción 1 — Cantidad total

**Pregunta visible:**
```
¿Cuántas bolsas tiene ahora el granjero?
```

**Tipo de respuesta:** Entrada numérica  
**Respuesta esperada:** 8 (porque 3 + 5 = 8)

---

#### 2.5 Retroalimentación para Interacción 1

##### Si responde **8**

**Título del recuadro:**
```
✓ Correcto
```

**Retroalimentación de Katia:**
```
El granjero tenía 3 bolsas y compró 5 más.

3 + 5 = 8

Ahora tiene 8 bolsas de alimento.
```

##### Si responde **otro valor**

**Título del recuadro:**
```
Revisemos la suma
```

**Retroalimentación de Katia:**
```
La cantidad total se obtiene sumando las bolsas que ya tenía y las que compró.

Tenía 3 bolsas y compró 5 más:

3 + 5 = 8

Entonces ahora tiene 8 bolsas.
```

---

#### 2.6 Interacción 2 — Suficiencia

**Pregunta visible:**
```
Si necesita 10 bolsas y tiene 8, ¿le alcanzan?
```

**Opciones de respuesta:**
- Sí
- No

**Respuesta esperada:** No

---

#### 2.7 Retroalimentación para Interacción 2

##### Si responde **"No"**

**Título del recuadro:**
```
✓ Correcto
```

**Retroalimentación de Katia:**
```
No le alcanzan. Tiene 8 bolsas, pero necesita 10.

Como 8 < 10, todavía le faltan algunas bolsas.
```

##### Si responde **"Sí"**

**Título del recuadro:**
```
Comparemos las cantidades
```

**Retroalimentación de Katia:**
```
Tiene 8 bolsas, pero necesita 10.

Como 8 < 10, todavía no le alcanzan.
```

---

#### 2.8 Interacción 3 — Cantidad faltante

**Pregunta visible:**
```
¿Cuántas bolsas le faltan?
```

**Tipo de respuesta:** Entrada numérica  
**Respuesta esperada:** 2 (porque 10 − 8 = 2)

---

#### 2.9 Retroalimentación para Interacción 3

##### Si responde **2**

**Título del recuadro:**
```
✓ Correcto
```

**Retroalimentación de Katia:**
```
Le faltan 2 bolsas.

Necesita 10 y tiene 8:

10 − 8 = 2
```

##### Si responde **otro valor**

**Título del recuadro:**
```
Miremos la diferencia
```

**Retroalimentación de Katia:**
```
Para saber cuántas bolsas faltan, comparamos la cantidad necesaria con 
la cantidad disponible.

Necesita 10 y tiene 8:

10 − 8 = 2

Le faltan 2 bolsas.
```

**Título visible:**

```
¿Qué son los números naturales?
```

**Texto visible:**
```
Los números naturales son los números que usamos para contar cantidades 
completas, ordenar elementos o indicar posiciones.

En este nivel usaremos:

N = {0, 1, 2, 3, 4, 5, …}

El cero representa ausencia de elementos. Por ejemplo, si no hay bolsas de 
alimento, podemos decir que hay 0 bolsas.
```

#### 2.13 Retroalimentación para el mini reto

##### Si omite el **0** (selecciona solo {4, 15})

**Título del recuadro:**
```
⚠ Atención a la convención
```

**Retroalimentación de Katia:**
```
En algunos libros los naturales empiezan en 1, pero en este nivel estamos 
usando:

N = {0, 1, 2, 3, 4, …}

Por eso, aquí el 0 también es natural.
```

**Misconception tag registrado:** `excluye_cero_de_naturales_pese_a_convencion`

##### Si selecciona **−2**

**Título del recuadro:**
```
⚠ Cuidado con los negativos
```

**Retroalimentación de Katia:**
```
Los números negativos como −2 no son naturales. Los naturales se usan para 
contar: no podemos contar una cantidad negativa de objetos.

Cuando necesitemos representar deudas, usaremos otro conjunto de números 
llamado enteros.
```

**Misconception tag registrado:** `incluye_negativos_en_naturales`

---

##### Si selecciona **√2** (raíz cuadrada de 2)

**Título del recuadro:**
```
⚠ Cuidado con los irracionales
```

**Retroalimentación de Katia:**
```
√2 es un número que no se puede escribir como una cantidad entera. Los 
naturales se usan para contar objetos completos, así que no incluimos 
números como √2.

Más adelante aprenderemos sobre números que no pueden escribirse como 
fracciones de enteros.
```

**Misconception tag registrado:** `incluye_no_enteros_en_naturales`

---

##### Si selecciona **2.5** (decimal)

**Título del recuadro:**
```
⚠ Cuidado con los decimales
```

**Retroalimentación de Katia:**
```
Los decimales como 2.5 no son naturales. Los naturales se usan para contar 
objetos completos. 2.5 representa una cantidad incompleta (dos y medio), 
así que no puede ser cantidad de objetos contados.

Cuando necesitemos representar partes, usaremos otro conjunto llamado 
números racionales.
```

**Misconception tag registrado:** `incluye_fracciones_en_naturales`

### A5. Notas pedagógicas inline

**[NOTA PEDAGÓGICA — Convención del cero]**
La elección de incluir 0 ∈ ℕ es una decisión institucional del nivel. Se declara explícitamente desde el inicio para evitar contradicciones en actividades posteriores de clasificación. Esto alinea con el estándar curricular colombiano (aunque algunos textos omiten el cero). La repetición en el mini reto refuerza esta convención.

**[NOTA PEDAGÓGICA — Situación concreta]**
La situación de las bolsas de alimento permite trabajar con números naturales en contexto sin introducir todavía negativos o fraccionarios. La progresión (cantidad total → suficiencia → cantidad faltante) crea un arco narrativo que facilita la comprensión. La validación de "¿alcanza?" introduce el significado de una cantidad, no solo el cálculo.

**[NOTA PEDAGÓGICA — Errores como señal]**
Los cinco tipos de error en el mini reto (omitir 0, incluir negativos, incluir raíces, incluir decimales) son misconceptions conocidas y documentadas. Cada uno se aborda con una retroalimentación específica que anticipa cómo se presentarán en actividades posteriores (clasificadores, detective de falsedades).
