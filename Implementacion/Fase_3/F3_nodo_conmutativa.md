```
Hola de nuevo, bienvenido a la máquina conmutativa. Aquí aprenderás cómo
```

#### 2.3 Definición y ejemplos base [NUEVO]

> Se presenta **antes** de la práctica, como definición y modelo a imitar.

**Diálogo de Katia (introduce la propiedad):**
```
Antes de empezar, veamos qué es conmutar.

Conmutar es intercambiar el orden de los números en una operación. Una 
operación es conmutativa si, al intercambiar el orden, el resultado no cambia:

a ⊕ b = b ⊕ a
```

**Ejemplo resuelto 1 (la suma SÍ es conmutativa):**
```
2 + 7 = 9   y   7 + 2 = 9

Mismo resultado: la suma es conmutativa.
```

**Ejemplo resuelto 2 (la resta NO es conmutativa):**
```
8 − 3 = 5   pero   3 − 8 = −5

Distinto resultado: la resta no es conmutativa. Cambiar el orden cambia el 
resultado (aquí, el signo).
```

#### 2.6 Retroalimentación [NUEVO]

##### Resultado correcto
```
✓ Correcto. Fíjate en la pareja de operaciones: si el resultado es el mismo al 
invertir el orden, esa operación es conmutativa.
```

##### Si el estudiante cree que la resta o la división son conmutativas
```
Cuidado: en la resta y en la división el orden SÍ cambia el resultado.

8 − 3 = 5  pero  3 − 8 = −5
12 ÷ 4 = 3  pero  4 ÷ 12 = 0,333…

Solo la suma y la multiplicación son conmutativas.
```
**Misconception:** `cree_que_resta_es_conmutativa` / `cree_que_division_es_conmutativa`

##### Error de cálculo en una operación
```
Revisa la operación con cuidado. Compara tu resultado con su pareja (la misma 
operación con el orden cambiado) para verificar.
```
**Misconception:** `error_de_calculo`

#### 2.7 Formalización (verbatim, con KaTeX restaurado)

> Se despliega tras la Operación 16 / Texto 9.

```
PROPIEDAD CONMUTATIVA

Una operación ⊕ es conmutativa si para todos los números a y b se cumple que:

a ⊕ b = b ⊕ a

• Operaciones conmutativas:    Suma (+) y Multiplicación (×).
• Operaciones NO conmutativas: Resta (−) y División (÷).
```

```
forma: la propiedad asociativa.
```

- Resta invertida: el signo cambia con un efecto de "voltear".
- Formalización: entra tras la última operación.

### A5. Notas pedagógicas inline [NUEVO]
**[NOTA — Descubrimiento por contraste]** La estructura "pareja de operaciones invertidas + ¿pasó lo mismo?" hace que el estudiante infiera la conmutatividad antes de formalizarla. Los casos de resta y división (donde NO se cumple) son tan importantes como los que sí, para evitar la sobregeneralización.

**[NOTA — Resta invertida cambia el signo]** El Texto 7 observa que 6 − 17 = −(17 − 6). Es una buena semilla para enteros y para el inverso aditivo (Máquina 5), pero conviene no exigirlo aún como regla.

**[NOTA — División no exacta]** 4 ÷ 12 = 0,333… enlaza con los decimales periódicos del Nivel 1; útil para recordar que el resultado puede no ser entero.
