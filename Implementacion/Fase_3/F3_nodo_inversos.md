```
El estudiante arrastra los números 5 y −5 agrupados como 5 − 5, y la máquina

máquina parpadea y Katia dice:
```
**Mensaje de Katia:**

#### 2.2 Texto de bienvenida (Texto 1 — verbatim)
**Diálogo de Katia:**
```
Bienvenido a la máquina de inversos aditivo y multiplicativo, donde aprenderás 
a encontrar aquellos números que, al operarlos con otros, anulan su valor; es 
decir, que el resultado de la operación dé un número neutro. Esta es quizás una 
de las propiedades más importantes para entender el funcionamiento de las 
ecuaciones y el despeje de incógnitas.
```

#### 2.3 Definición y ejemplos base [NUEVO]

**Diálogo de Katia (introduce la propiedad):**
```
Antes de empezar, veamos qué es un inverso.

Un inverso es el número que, al operarse con otro, lo "cancela" llevándolo al 
elemento neutro:

- El inverso aditivo (opuesto) de a es −a, porque a + (−a) = 0.
- El inverso multiplicativo (recíproco) de a es 1/a, porque a × (1/a) = 1.
```

**Ejemplo resuelto 1 (inverso aditivo):**
```
El opuesto de 6 es −6, porque:

6 + (−6) = 0

Se llega al neutro de la suma (0).
```

**Ejemplo resuelto 2 (inverso multiplicativo):**
```
El recíproco de 4 es 1/4, porque:

4 × (1/4) = 1

Se llega al neutro de la multiplicación (1).
```

#### 2.4 Instrucciones (verbatim, adaptadas a la mecánica)
```
Cada operación muestra un número y el resultado neutro (0 o 1). Escribe en la 
casilla el número que cancela al primero para llegar a ese resultado.
```

> **Mecánica (verbatim):** En esta máquina la interacción cambia: el objetivo es que el estudiante entienda cómo cancelar números. Las operaciones se presentan con uno de los números (el que se quiere cancelar), una casilla para que el estudiante escriba el número que lo cancela, y el resultado de la operación ya escrito (el número neutro).

#### 2.5 Serie de operaciones con diálogos de Katia (verbatim)

**Inverso aditivo:**

**Operación 1:** 5 + (___) = 0 → el estudiante escribe **−5**
**Operación 2:** 7 + (___) = 0 → el estudiante escribe **−7**

**Texto 2 (Katia):**
```
Vaya, vaya: para encontrar el valor neutro de la suma, simplemente teníamos que 
sumarle a un número su contraparte negativa, y así cancelarlo. Pero ¿qué pasaría

```

**Operación 3:** −15 + (___) = 0 → el estudiante escribe **+15**
**Operación 4:** −9 + (___) = 0 → el estudiante escribe **+9**

**Texto 3 (Katia):**
```
Si el número original tuviera un valor negativo, simplemente sería sumarle su

```

**Inverso multiplicativo:**

**Operación 5:** 5 × (___) = 1 → el estudiante escribe **1/5**
**Operación 6:** 10 × (___) = 1 → el estudiante escribe **1/10**

**Texto 4 (Katia):**
```
Ahora, para el inverso multiplicativo, para encontrar el valor neutro 
simplemente bastará con multiplicar el número original por su recíproco; es 
decir, el número original dividiendo a 1.
```

> [NOTA — el 0 no tiene recíproco] El inverso multiplicativo existe para todo número excepto el 0 (1/0 no está definido). Conviene mencionarlo en banda Avanzado.

#### 2.6 Retroalimentación [NUEVO]

##### Inverso aditivo correcto
```
✓ Correcto. El opuesto cambia el signo: a + (−a) = 0. Al sumar un número con su 
opuesto, se cancelan y llegamos al neutro 0.
```

##### Inverso multiplicativo correcto
```
✓ Correcto. El recíproco es 1 dividido por el número: a × (1/a) = 1. Al 
multiplicar un número por su recíproco, llegamos al neutro 1.
```

##### Si confunde opuesto con recíproco
```
Cuidado con cuál inverso usar:
- Para llegar a 0 (suma): el OPUESTO, que cambia el signo. Opuesto de 5 es −5.
- Para llegar a 1 (multiplicación): el RECÍPROCO, que es 1/número. Recíproco de 
  5 es 1/5.
```
**Misconception:** `confunde_opuesto_con_reciproco`

##### Si no cambia el signo del opuesto
```
El opuesto tiene el signo contrario. El opuesto de 7 es −7 (no 7), porque 
7 + (−7) = 0.
```
**Misconception:** `no_cambia_el_signo_del_opuesto`

#### 2.7 Formalización (verbatim, con KaTeX restaurado)
```
INVERSO ADITIVO (U OPUESTO)

Para todo número a existe un número −a (el opuesto de a) tal que:

a + (−a) = 0


INVERSO MULTIPLICATIVO (O RECÍPROCO)

Para todo número a ≠ 0 existe un número 1/a (el recíproco de a) tal que:

a × (1/a) = 1
```

### A5. Notas pedagógicas inline [NUEVO]
**[NOTA — Inverso = llegar al neutro]** El nodo cierra el nivel conectando con M04: el inverso es el número que, operado con el original, produce el elemento neutro (0 para la suma, 1 para la multiplicación). Esa conexión da sentido a las dos máquinas finales.

**[NOTA — Mecánica de cancelación]** A diferencia de las otras máquinas (escribir el resultado), aquí se da el resultado (neutro) y se pide el operando que cancela. Es un paso hacia el despeje de ecuaciones.

**[NOTA — El 0 no tiene recíproco]** 1/0 no está definido; mencionarlo en Avanzado evita una sobregeneralización.

**[NOTA — Puente a ecuaciones]** El Texto 1 lo anticipa: sumar el opuesto o multiplicar por el recíproco es justo lo que se hace para despejar una incógnita.
