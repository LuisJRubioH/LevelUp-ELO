### A2. Guión de pantalla (texto íntegro por pantalla)

#### 2.1 Apertura narrativa

**Texto visible:**
```
Bienvenido al edificio de la suma.

El cartel de la entrada mostraba una pregunta sencilla:

Tienes 3 manzanas.

Tu amigo te da 2 más.

¿Cuántas tienes ahora?

Felipe aparece frente a un puesto de frutas.

Tiene una canasta vacía.

También tiene una mesa con manzanas, peras, mangos, uvas y bananas.

Katia se posa junto a la canasta y mira al estudiante.

Katia pregunta:
"Si una cantidad llega desde un lado y otra cantidad llega desde otro,
¿cómo sabemos cuántas hay en total?"

No responde de inmediato.

Primero invita a mirar.

Primero hay 3 manzanas sobre la mesa.

Luego llegan 2 manzanas más.

No desaparece ninguna.

No se quita nada.

Solo se juntan.

La suma aparece cuando queremos reunir cantidades.

La suma no es solo una cuenta escrita.

También es una acción:

juntar,

agregar,

reunir,

combinar,

y luego mirar el total.

Katia dice:
"Antes de arrastrar frutas, descubramos qué está pasando."

El objetivo no es memorizar 3 + 2.

El objetivo es entender por qué 3 + 2 representa una sola cantidad total.
```

#### 2.2 Descubrimiento guiado

**Texto visible:**
```
Observemos la primera escena.

Felipe pone 3 manzanas rojas en la canasta.

Después su amigo pone 2 manzanas verdes.

Si contamos todas las manzanas que quedaron juntas, vemos:

1,

2,

3,

4,

5.

Entonces la canasta tiene 5 manzanas.

La frase matemática es:

3 + 2 = 5

El 3 representa la primera cantidad.

El 2 representa la cantidad que se agregó.

El 5 representa el total.

Ahora cambiemos la escena.

Felipe pone 4 peras.

Luego agrega 1 mango.

Después agrega 2 uvas.

La canasta ya no tiene solo dos grupos.

Tiene tres grupos.

Katia pregunta:
"¿La suma sirve solo para dos cantidades?"

No.

También podemos juntar más de dos cantidades.

Primero juntamos 4 y 1.

4 + 1 = 5

Luego juntamos esas 5 frutas con 2 uvas.

5 + 2 = 7

Entonces:

4 + 1 + 2 = 7

Ahora viene un caso límite.

Felipe tiene 6 frutas.

Katia dice que se agregan 0 bananas.

¿Qué cambia?

No aparece ninguna banana.

No se agrega ninguna fruta.

El total sigue siendo 6.

6 + 0 = 6

Este ejemplo es importante porque el 0 también puede ser sumando.

Pero sumar 0 no aumenta la cantidad.

Contraejemplo:

Si quitamos frutas de la canasta, ya no estamos sumando.

Si Felipe tenía 6 y retira 2, la acción es otra.

Eso será la resta.

Entonces, ¿qué hace especial a la suma?

La suma junta cantidades y produce un total.
```

#### 2.3 Definición formal integrada + ejemplos base

**Texto visible:**
```
Ya descubrimos la idea con frutas.

Ahora la escribimos con lenguaje matemático.

La suma es una operación que combina dos o más cantidades llamadas sumandos
para obtener una cantidad total llamada suma o resultado.
```

**Definición formal en KaTeX:**

$$a+b=c$$

**Lectura de la definición:**
```
En la expresión a + b = c:

a es un sumando.

b es otro sumando.

c es el total.

El símbolo + indica que las cantidades se juntan.

El símbolo = indica que ambos lados representan la misma cantidad.

Katia resume:
"Los sumandos son las partes; el resultado es el todo."
```

##### Ejemplo 1 (básico) — 3 manzanas y 2 más

**Enunciado:**
```
Felipe tiene 3 manzanas.

Su amigo le da 2 manzanas más.

¿Cuántas manzanas tiene ahora?
```

**Solución paso a paso:**
```
Paso 1. Identificamos la primera cantidad:

3 manzanas.

Paso 2. Identificamos la cantidad que llega:

2 manzanas.

Paso 3. Como las cantidades se juntan, usamos suma:

3 + 2

Paso 4. Contamos o calculamos:

3 + 2 = 5

Resultado:

Felipe tiene 5 manzanas.
```

##### Ejemplo 2 (intermedio) — tres grupos de frutas

**Enunciado:**
```
Felipe pone en la canasta 4 peras, 1 mango y 2 uvas.

¿Cuántas frutas hay en total?
```

**Solución paso a paso:**
```
Paso 1. Identificamos los tres sumandos:

4,

1,

2.

Paso 2. Juntamos los dos primeros:

4 + 1 = 5

Paso 3. Sumamos el tercer grupo:

5 + 2 = 7

Paso 4. Escribimos la suma completa:

4 + 1 + 2 = 7

Resultado:

Hay 7 frutas en total.
```

##### Ejemplo 3 (trampa común) — sumar cero

**Enunciado:**
```
La canasta tiene 6 frutas.

Felipe agrega 0 bananas.

¿Cuántas frutas hay ahora?
```

**Solución paso a paso:**
```
Paso 1. La cantidad inicial es 6.

Paso 2. La cantidad agregada es 0.

Paso 3. Sumar 0 significa no agregar objetos nuevos.

Paso 4. Calculamos:

6 + 0 = 6

Resultado:

La canasta sigue teniendo 6 frutas.

Katia advierte:
"El 0 participa en la suma, pero no cambia el total."
```

**Transición hacia la práctica:**
```
Ahora sí vamos a usar la canasta.

Arrastraremos frutas.

Contaremos el total.

Y revisaremos qué representa cada sumando.
```

#### 2.4 Práctica interactiva — Canasta de Felipe

**Instrucción visible:**
```
Arrastra las frutas indicadas a la canasta y escribe el total.

Si usas teclado, selecciona una fruta, presiona Enter y luego selecciona la canasta.

Katia te dará retroalimentación después de cada intento.
```

##### S1 — Manzanas del cartel

**Situación visible:**
```
Felipe tiene 3 manzanas.

Su amigo le da 2 manzanas más.

¿Cuántas manzanas hay en la canasta?
```

**Operación esperada:** `3 + 2`  
**Respuesta esperada:** `5`

**Retroalimentación correcta:**
```
Correcto.

Juntaste 3 manzanas y 2 manzanas.

3 + 2 = 5.
```

**Retroalimentación si omite un grupo:**
```
Revisa la canasta.

Contaste solo uno de los grupos.

La suma necesita juntar las 3 manzanas iniciales y las 2 que llegaron después.
```

##### S2 — Tres grupos

**Situación visible:**
```
Felipe pone 4 peras, 1 mango y 2 uvas.

¿Cuántas frutas hay en total?
```

**Operación esperada:** `4 + 1 + 2`  
**Respuesta esperada:** `7`

**Retroalimentación correcta:**
```
Muy bien.

Primero 4 + 1 = 5.

Luego 5 + 2 = 7.
```

**Retroalimentación si cuenta un sumando dos veces:**
```
Katia nota una fruta repetida en tu conteo.

Cada fruta cuenta una vez.

Vuelve a separar los grupos:

4,

1,

2.
```

##### S3 — El cero en la suma

**Situación visible:**
```
La canasta tiene 6 frutas.

Felipe agrega 0 bananas.

¿Cuántas frutas hay ahora?
```

**Operación esperada:** `6 + 0`  
**Respuesta esperada:** `6`

**Retroalimentación correcta:**
```
Exacto.

Agregar 0 bananas no cambia el total.

6 + 0 = 6.
```

**Retroalimentación si responde 7 o agrega una banana imaginaria:**
```
El 0 no significa "una fruta".

Significa que no se agregó ninguna banana.

Por eso el total se conserva.
```

##### S4 — Verificación del total

**Situación visible:**
```
Katia muestra una canasta con 8 frutas.

Felipe dice que la construyó con 5 frutas y luego 3 más.

¿La afirmación de Felipe es correcta?
```

**Operación esperada:** `5 + 3 = 8`  
**Respuesta esperada:** `sí`

**Retroalimentación correcta:**
```
Sí.

5 + 3 = 8.

La suma coincide con el total visible.
```

**Retroalimentación si responde no:**
```
Cuenta de nuevo.

Si ya hay 5 frutas y se agregan 3,
el total llega a 8.
```

#### 2.5 Formalización de consolidación

**Texto visible:**
```
La suma permite reunir cantidades.

Cuando escribimos:

a + b = c

decimos que a y b son sumandos.

El resultado c es el total.

En el conjunto de los números naturales, sumar dos naturales produce otro natural.

En este nivel usamos la suma para modelar situaciones donde las cantidades se
agregan o se reúnen.
```

**Propiedades visibles [NUEVO]:**
```
Conmutatividad:

a + b = b + a

Juntar 3 y luego 2 da el mismo total que juntar 2 y luego 3.

Elemento neutro:

a + 0 = a

Sumar 0 no cambia la cantidad.
```

#### 2.7 Consolidación narrativa extendida [NUEVO]

**Texto visible si el estudiante necesita repasar antes de salir:**
```
Katia abre una libreta pequeña.

En la primera página dibuja dos círculos.

En un círculo escribe:

partes.

En el otro círculo escribe:

total.

Luego une los círculos con una flecha.

La flecha dice:

sumar.

Katia explica:
"Cuando sumamos, no estamos adivinando un número.
Estamos siguiendo el viaje de las partes hasta formar un todo."

Felipe mira la canasta.

La canasta no muestra operaciones.

Muestra frutas.

Pero cada grupo de frutas puede convertirse en un sumando.

Un grupo de 3 manzanas puede escribirse como 3.

Un grupo de 2 manzanas puede escribirse como 2.

La canasta completa puede escribirse como 5.

La operación conecta esas tres ideas:

3 + 2 = 5

Katia tapa el resultado por un momento.

Pregunta:
"Si solo ves 3 + 2, ¿qué esperas encontrar en la canasta?"

La respuesta no sale de memoria.

Sale de imaginar los grupos.

Primero hay 3.

Después llegan 2.

El total debe incluir los dos grupos.

Por eso no puede ser 3.

Por eso no puede ser 2.

Debe ser 5.

Ahora Katia tapa los sumandos.

Solo deja visible el total:

5.

Pregunta:
"¿Podría una canasta de 5 frutas venir de 4 + 1?"

Sí.

¿Podría venir de 2 + 3?

Sí.

¿Podría venir de 5 + 0?

Sí.

Esto muestra una idea importante.

Una misma cantidad total puede formarse de varias maneras.

La suma no solo calcula.

También describe cómo se formó una cantidad.

Felipe prueba con otra canasta.

Pone 2 peras.

Pone 2 mangos.

Pone 2 uvas.

Katia pregunta:
"¿Cuál es una forma ordenada de sumar tres grupos iguales?"

Podemos sumar de izquierda a derecha:

2 + 2 = 4

4 + 2 = 6

También podemos mirar todos los grupos:

2 + 2 + 2 = 6

En Nivel 2, esta idea será útil más adelante.

Cuando sumamos grupos iguales muchas veces,
aparece una operación nueva:

la multiplicación.

Pero todavía no necesitamos usarla.

Por ahora basta con entender que cada grupo aporta al total.

Katia vuelve al caso del 0.

Pone una etiqueta que dice:

0 bananas.

No arrastra bananas.

No cambia el contador.

La canasta se queda igual.

Pregunta:
"¿Por qué el contador no subió?"

Porque no se agregó ningún objeto.

El 0 no es una fruta invisible.

El 0 representa ausencia de frutas nuevas.

Por eso:

6 + 0 = 6

Y también:

0 + 6 = 6

Felipe sonríe.

Ahora entiende que el orden de los grupos puede cambiar,
pero el total sigue siendo el mismo cuando los grupos son los mismos.

Katia no lo convierte todavía en una regla larga.

Solo deja una pista:

"Cuando una propiedad aparece muchas veces, más adelante le damos nombre."

En el edificio de suma, el foco sigue siendo juntar.

Juntar no significa mezclar sin contar.

Juntar significa reconocer las partes.

Luego unirlas.

Luego verificar el total.

Si el total no coincide, revisamos:

¿omití un grupo?

¿conté un objeto dos veces?

¿confundí 0 con 1?

¿escribí el total donde iba un sumando?

Estas preguntas ayudan a corregir sin borrar el razonamiento.

Katia cierra la libreta.

Dice:
"Una suma bien entendida siempre puede explicarse con palabras, objetos y símbolos."

Con palabras:

tengo 3 y recibo 2 más.

Con objetos:

veo 3 frutas y luego 2 frutas.

Con símbolos:

3 + 2 = 5.

Si esas tres representaciones cuentan la misma historia,
la suma tiene sentido.

Ahora el edificio queda completo.

La canasta se guarda.

El mapa de la ciudad vuelve a aparecer.

La puerta siguiente se ilumina suavemente.

La resta espera al otro lado.

Antes de salir, Katia deja tres señales en la puerta.

Primera señal:

si aparecen cantidades que se reúnen, piensa en suma.

Segunda señal:

si aparece un total, pregúntate qué partes lo formaron.

Tercera señal:

si aparece 0, no inventes objetos nuevos.

Felipe repite la idea con sus propias palabras.

"Sumar es juntar partes y revisar el total."

Katia asiente.

Esa frase queda escrita en la pantalla.

El estudiante puede volver a leerla.

También puede abrir los ejemplos base.

También puede repetir una situación de práctica.

El nodo no busca velocidad.

Busca que la operación tenga sentido.

Cuando el estudiante presiona continuar,
la canasta se transforma en un pequeño icono del mapa.

Ese icono marca que el edificio de la suma fue explorado.

La ciudad queda lista para comparar:

si sumar junta,

restar quitará,

comparará,

y mostrará qué falta.

Katia guarda la última pregunta:

"¿Qué parte cambió?"

"¿Qué parte se mantuvo?"

"¿Qué total resultó?"

Con esas tres preguntas,

la suma queda lista para usarse en problemas nuevos.
```

**[NOTA — suma como acción]** El nodo evita presentar la suma como símbolo vacío.
Primero se representa como juntar objetos; luego se formaliza.

sin convertirlo todavía en una lección abstracta de propiedades.
